# 1304. Find N Unique Integers Sum up to Zero

[Problem Link](https://leetcode.com/problems/find-n-unique-integers-sum-up-to-zero/)

## Description
Given integer n, return any array of n unique integers that sum to zero.

## Examples
Input: n = 5 → [-7,-1,1,3,4]
Input: n = 3 → [-1,0,1]

## Constraints
- 1 <= n <= 1000
