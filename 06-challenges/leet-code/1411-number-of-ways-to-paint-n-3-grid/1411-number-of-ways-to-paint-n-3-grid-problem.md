# 1411. Number Of Ways To Paint N 3 Grid

**Difficulty:** Hard
**Link:** https://leetcode.com/problems/number-of-ways-to-paint-n-3-grid/

---

## Problem Statement

Return the number of ways to paint an `n x 3` grid such that no two adjacent cells share the same color using 3 colors. Return mod 10^9+7.

---

## Examples

**Example 1:**
```
Input:  n=1
Output: 12
```

**Example 2:**
```
Input:  n=2
Output: 54
```

---

## Constraints

- `1 <= n <= 5000`
