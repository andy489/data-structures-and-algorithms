# 986. Interval List Intersections — Solution

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/interval-list-intersections/

---

## Solution: Two Pointers — O(m+n) time, O(1) space

**Idea:** Use two pointers; compute intersection of current intervals; advance the pointer with the earlier end.

**Complexity:**

| | |
|---|---|
| Time | O(m+n) |
| Space | O(1) extra |
