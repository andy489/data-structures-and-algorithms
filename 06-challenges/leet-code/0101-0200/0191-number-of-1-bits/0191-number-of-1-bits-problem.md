# 191. Number of 1 Bits

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/number-of-1-bits/

---

## Problem Statement

Write a function that takes the binary representation of a positive integer and returns the number of set bits it has (also known as the [Hamming weight](http://en.wikipedia.org/wiki/Hamming_weight)).

---

## Examples

**Example 1:**
```
Input:  n = 11
Output: 3
Explanation: The input binary string 1011 has three set bits.
```

**Example 2:**
```
Input:  n = 128
Output: 1
Explanation: The input binary string 10000000 has one set bit.
```

**Example 3:**
```
Input:  n = 2147483645
Output: 30
```

---

## Constraints

- `1 <= n <= 2^31 - 1`
