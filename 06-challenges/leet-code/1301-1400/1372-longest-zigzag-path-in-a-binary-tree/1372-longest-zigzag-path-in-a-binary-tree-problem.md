# 1372. Longest ZigZag Path in a Binary Tree

[Problem Link](https://leetcode.com/problems/longest-zigzag-path-in-a-binary-tree/)

## Description
Return the longest ZigZag path in a binary tree (alternating left/right child selections). Length = number of edges.

## Examples
Input: root = [1,null,1,1,1,null,null,1,1,null,1,null,null,null,1] → 3

## Constraints
- Number of nodes in [1, 50000]
