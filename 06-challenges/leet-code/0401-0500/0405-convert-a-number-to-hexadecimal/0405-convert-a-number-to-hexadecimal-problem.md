# 405. Convert a Number to Hexadecimal

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/convert-a-number-to-hexadecimal/

---

## Problem Statement

Given a 32-bit integer `num`, return a string representing its hexadecimal form. For negative integers, use two's complement representation. The output must use lowercase letters (`a-f`) and must not have leading zeros (except the result itself is `0`).

You may not use any built-in library methods for direct conversion.

---

## Examples

**Example 1:**
```
Input:  num = 26
Output: "1a"
```

**Example 2:**
```
Input:  num = -1
Output: "ffffffff"
```

---

## Constraints

- `-2^31 <= num <= 2^31 - 1`
