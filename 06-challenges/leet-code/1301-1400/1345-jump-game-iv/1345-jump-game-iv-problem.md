# 1345. Jump Game IV

[Problem Link](https://leetcode.com/problems/jump-game-iv/)

## Description
Given array arr, start at index 0. At index i you can jump to i+1, i-1, or any j where arr[j]==arr[i]. Return min jumps to reach last index.

## Examples
Input: arr = [100,-23,-23,404,100,23,23,23,3,404] → 3

## Constraints
- 1 <= arr.length <= 5 * 10^4
- -10^8 <= arr[i] <= 10^8
