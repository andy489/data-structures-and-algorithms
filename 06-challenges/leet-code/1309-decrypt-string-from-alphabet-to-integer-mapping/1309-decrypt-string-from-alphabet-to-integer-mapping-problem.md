# 1309. Decrypt String from Alphabet to Integer Mapping

[Problem Link](https://leetcode.com/problems/decrypt-string-from-alphabet-to-integer-mapping/)

## Description
Given string s consisting of digits and '#', decode it: single digit d maps to 'a'+d-1, two digits d1d2 followed by '#' map to 'a'+d1d2-1.

## Examples
Input: s = "10#11#12" → "jkab"

## Constraints
- 1 <= s.length <= 1000
- s consists of digits and '#'
