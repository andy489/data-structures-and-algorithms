# 610. Triangle Judgement — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/triangle-judgement/

---

## Solution: IF Expression — O(n) time, O(1) space

**Idea:** A triangle is valid if the sum of any two sides exceeds the third. Use SQL IF() to output Yes/No.

**Complexity:**

| | |
|---|---|
| Time | O(n) — single scan |
| Space | O(1) — no extra storage |
