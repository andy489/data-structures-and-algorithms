# 1218. Longest Arithmetic Subsequence of Given Difference

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/longest-arithmetic-subsequence-of-given-difference/

---

## Problem Statement

Given an integer array `arr` and an integer `difference`, find the length of the longest subsequence in `arr` which is an arithmetic sequence such that the difference between adjacent elements in the subsequence equals `difference`.

---

## Examples

**Example 1:**
```
Input:  arr = [1,2,3,4], difference = 1
Output: 4
```

---

## Constraints

- `1 <= arr.length <= 10^5`
- `-10^4 <= arr[i], difference <= 10^4`
