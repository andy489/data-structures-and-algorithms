# 1334. Find the City With the Smallest Number of Neighbors at a Threshold Distance

[Problem Link](https://leetcode.com/problems/find-the-city-with-the-smallest-number-of-neighbors-at-a-threshold-distance/)

## Description
Given n cities and weighted edges, find the city with the fewest number of cities reachable within distanceThreshold. If tie, return the city with greatest number.

## Examples
Input: n=4, edges=[[0,1,3],[1,2,1],[1,3,4],[2,3,1]], distanceThreshold=4 → 3

## Constraints
- 2 <= n <= 100
