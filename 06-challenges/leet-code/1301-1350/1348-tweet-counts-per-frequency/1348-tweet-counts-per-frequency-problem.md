# 1348. Tweet Counts Per Frequency

[Problem Link](https://leetcode.com/problems/tweet-counts-per-frequency/)

## Description
Design TweetCounts class: recordTweet(tweetName, time), getTweetCountsPerFrequency(freq, tweetName, startTime, endTime) returns counts per time interval.

## Examples
getTweetCountsPerFrequency("minute", "tweet3", 0, 60) → [2]

## Constraints
- 0 <= time <= 10^9
- freq is "minute", "hour", or "day"
