# 1344. Angle Between Hands of a Clock

[Problem Link](https://leetcode.com/problems/angle-between-hands-of-a-clock/)

## Description
Given hour and minutes, return the smaller angle between the two clock hands.

## Examples
Input: hour = 12, minutes = 30 → 165.0

## Constraints
- 1 <= hour <= 12
- 0 <= minutes <= 59
