# 1414. Find The Minimum Number Of Fibonacci Numbers Whose Sum Is K

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/find-the-minimum-number-of-fibonacci-numbers-whose-sum-is-k/

---

## Problem Statement

Return the minimum number of Fibonacci numbers whose sum equals `k`. Each Fibonacci number can be used multiple times.

---

## Examples

**Example 1:**
```
Input:  k=7
Output: 2
```

**Example 2:**
```
Input:  k=10
Output: 2
```

**Example 3:**
```
Input:  k=19
Output: 3
```

---

## Constraints

- `1 <= k <= 10^9`
