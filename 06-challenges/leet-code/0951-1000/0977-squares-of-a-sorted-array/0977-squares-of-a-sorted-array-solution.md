# 977. Squares of a Sorted Array — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/squares-of-a-sorted-array/

---

## Solution: Two Pointers — O(n) time, O(n) space

**Idea:** Largest squares are at the ends. Use two pointers to fill result from back.

**Complexity:**

| | |
|---|---|
| Time | O(n) |
| Space | O(n) — result array |
