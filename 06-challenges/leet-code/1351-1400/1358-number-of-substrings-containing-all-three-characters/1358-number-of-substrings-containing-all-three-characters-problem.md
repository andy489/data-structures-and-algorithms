# 1358. Number of Substrings Containing All Three Characters

[Problem Link](https://leetcode.com/problems/number-of-substrings-containing-all-three-characters/)

## Description
Given string s consisting of 'a', 'b', 'c', return number of substrings containing at least one of each.

## Examples
Input: s = "abcabc" → 10

## Constraints
- 3 <= s.length <= 5 * 10^4
