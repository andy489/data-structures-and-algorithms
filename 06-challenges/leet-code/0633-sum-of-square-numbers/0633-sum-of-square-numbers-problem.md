# 633. Sum of Square Numbers

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/sum-of-square-numbers/

---

## Problem Statement

Given a non-negative integer `c`, decide whether there're two integers `a` and `b` such that `a^2 + b^2 = c`.

---

## Examples

**Example 1:**
```
Input:  c = 5
Output: true
Explanation: 1^2 + 2^2 = 5
```

**Example 2:**
```
Input:  c = 3
Output: false
```

---

## Constraints

- `0 <= c <= 2^31 - 1`
