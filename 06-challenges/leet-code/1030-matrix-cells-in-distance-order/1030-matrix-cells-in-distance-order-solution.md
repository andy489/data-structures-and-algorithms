# 1030. Matrix Cells in Distance Order — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/matrix-cells-in-distance-order/

---

## Solution: Sort — O(r·c·log(r·c)) time, O(r·c) space

**Idea:** Collect all cells and sort by Manhattan distance from center.

**Complexity:**

| | |
|---|---|
| Time | O(r·c·log(r·c)) |
| Space | O(r·c) |
