# 1361. Validate Binary Tree Nodes

[Problem Link](https://leetcode.com/problems/validate-binary-tree-nodes/)

## Description
Given n nodes and leftChild, rightChild arrays, determine if they form a valid binary tree.

## Examples
Input: n=4, leftChild=[1,-1,3,-1], rightChild=[2,-1,-1,-1] → true

## Constraints
- n == leftChild.length == rightChild.length
- 1 <= n <= 10^4
