# 1380. Lucky Numbers in a Matrix

[Problem Link](https://leetcode.com/problems/lucky-numbers-in-a-matrix/)

## Description
Return all lucky numbers in matrix — element that is the minimum of its row and maximum of its column.

## Examples
Input: matrix = [[3,7,8],[9,11,13],[15,16,17]] → [15]

## Constraints
- m == matrix.length, n == matrix[i].length
- 1 <= m, n <= 50
