# 1300. Sum of Mutated Array Closest to Target

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/sum-of-mutated-array-closest-to-target/

---

## Problem Statement

Given an integer array `arr` and a target value `target`, return the integer `value` such that when we change all the integers larger than `value` in the given array to equal `value`, the sum of the array gets as close as possible to `target`.

In case of a tie, return the minimum such integer.

---

## Examples

**Example 1:**
```
Input:  arr = [4,9,3], target = 10
Output: 3
```

---

## Constraints

- `1 <= arr.length <= 10^4`
- `1 <= arr[i], target <= 10^5`
