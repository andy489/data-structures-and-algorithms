# 1373. Maximum Sum BST in Binary Tree

[Problem Link](https://leetcode.com/problems/maximum-sum-bst-in-binary-tree/)

## Description
Given binary tree, find the maximum sum of all keys of any sub-tree which is a BST.

## Examples
Input: root = [1,4,3,2,4,2,5,null,null,null,null,null,null,4,6] → 20

## Constraints
- Number of nodes in [1, 40000]
- -4 * 10^4 <= Node.val <= 4 * 10^4
