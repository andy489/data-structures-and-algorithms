# 1415. The K Th Lexicographical String Of All Happy Strings Of Length N

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/the-k-th-lexicographical-string-of-all-happy-strings-of-length-n/

---

## Problem Statement

A happy string uses only 'a','b','c' and no two adjacent chars are equal. Return the k-th lexicographically smallest happy string of length n, or empty if fewer than k exist.

---

## Examples

**Example 1:**
```
Input:  n=1,k=3
Output: "c"
```

**Example 2:**
```
Input:  n=1,k=4
Output: ""
```

**Example 3:**
```
Input:  n=3,k=9
Output: "cab"
```

---

## Constraints

- `1 <= n <= 10`
- `1 <= k <= 100`
