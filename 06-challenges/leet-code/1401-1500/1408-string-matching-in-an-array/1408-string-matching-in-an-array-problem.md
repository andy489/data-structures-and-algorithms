# 1408. String Matching In An Array

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/string-matching-in-an-array/

---

## Problem Statement

Given an array of strings `words`, return all strings that are a substring of another word in the array.

---

## Examples

**Example 1:**
```
Input:  words = ["mass","as","hero","superhero"]
Output: ["as","hero"]
```

**Example 2:**
```
Input:  words = ["leetcode","et","code"]
Output: ["et","code"]
```

---

## Constraints

- `1 <= words.length <= 100`
- `1 <= words[i].length <= 30`
- `words[i] contains only lowercase letters`
