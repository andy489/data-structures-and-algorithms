# 1447. Simplified Fractions

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/simplified-fractions/

---

## Problem Statement

Return all simplified fractions between 0 (exclusive) and 1 (exclusive) with denominator at most `n`.

---

## Examples

**Example 1:**
```
Input:  n=2
Output: ["1/2"]
```

**Example 2:**
```
Input:  n=3
Output: ["1/2","1/3","2/3"]
```

**Example 3:**
```
Input:  n=4
Output: ["1/2","1/3","1/4","2/3","3/4"]
```

---

## Constraints

- `1 <= n <= 100`
