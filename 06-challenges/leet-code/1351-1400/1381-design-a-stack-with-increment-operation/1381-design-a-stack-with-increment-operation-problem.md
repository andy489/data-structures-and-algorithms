# 1381. Design a Stack With Increment Operation

[Problem Link](https://leetcode.com/problems/design-a-stack-with-increment-operation/)

## Description
Design stack with maxSize, push, pop, and increment(k, val) which adds val to bottom k elements.

## Examples
customStack.push(1); customStack.push(2); customStack.increment(2, 100); customStack.pop() → 102

## Constraints
- 1 <= maxSize <= 1000
