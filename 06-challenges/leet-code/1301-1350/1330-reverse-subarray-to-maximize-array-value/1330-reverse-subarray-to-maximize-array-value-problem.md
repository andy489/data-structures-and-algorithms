# 1330. Reverse Subarray To Maximize Array Value

[Problem Link](https://leetcode.com/problems/reverse-subarray-to-maximize-array-value/)

## Description
Given integer array nums, you may reverse exactly one subarray. Return the maximum possible sum of |nums[i]-nums[i+1]|.

## Examples
Input: nums = [2,3,1,5,4] → 10

## Constraints
- 1 <= nums.length <= 3 * 10^4
- -10^5 <= nums[i] <= 10^5
