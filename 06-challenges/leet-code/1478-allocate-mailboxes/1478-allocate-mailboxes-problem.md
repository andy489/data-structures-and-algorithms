# 1478. Allocate Mailboxes

**Difficulty:** Hard
**Link:** https://leetcode.com/problems/allocate-mailboxes/

---

## Problem Statement

Given houses on a number line and k mailboxes, place mailboxes to minimize total distance sum. Return minimum.

---

## Examples

**Example 1:**
```
Input:  houses=[1,4,8,10,20],k=3
Output: 5
```

**Example 2:**
```
Input:  houses=[2,3,5,12,18],k=2
Output: 9
```

---

## Constraints

- `1 <= k <= houses.length <= 100`
- `1 <= houses[i] <= 10^4`
- `houses has distinct values`
