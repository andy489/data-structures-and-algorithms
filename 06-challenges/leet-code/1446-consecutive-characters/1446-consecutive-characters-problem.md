# 1446. Consecutive Characters

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/consecutive-characters/

---

## Problem Statement

Return the power of string `s` = maximum number of consecutive identical characters.

---

## Examples

**Example 1:**
```
Input:  s="leetcode"
Output: 2
```

**Example 2:**
```
Input:  s="abbcccddddeeeeedcba"
Output: 5
```

---

## Constraints

- `1 <= s.length <= 500`
- `s consists of only lowercase English letters`
