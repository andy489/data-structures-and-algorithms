# 1385. Find the Distance Value Between Two Arrays

[Problem Link](https://leetcode.com/problems/find-the-distance-value-between-two-arrays/)

## Description
Return the number of elements in arr1 such that for all elements in arr2, |arr1[i] - arr2[j]| > d.

## Examples
Input: arr1=[4,5,8], arr2=[10,9,1,8], d=2 → 2

## Constraints
- 1 <= arr1.length, arr2.length <= 500
- -1000 <= arr1[i], arr2[j] <= 1000
- 0 <= d <= 100
