# 1351. Count Negative Numbers in a Sorted Matrix

[Problem Link](https://leetcode.com/problems/count-negative-numbers-in-a-sorted-matrix/)

## Description
Given m×n matrix sorted in non-increasing order (both row and column), count the number of negative numbers.

## Examples
Input: grid = [[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]] → 8

## Constraints
- m == grid.length, n == grid[i].length
- 1 <= m, n <= 100
