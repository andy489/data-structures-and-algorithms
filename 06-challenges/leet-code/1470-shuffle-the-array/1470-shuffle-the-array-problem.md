# 1470. Shuffle The Array

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/shuffle-the-array/

---

## Problem Statement

Return array [x1,y1,x2,y2,...,xn,yn] from nums = [x1,...,xn,y1,...,yn].

---

## Examples

**Example 1:**
```
Input:  nums=[2,5,1,3,4,7],n=3
Output: [2,3,5,4,1,7]
```

**Example 2:**
```
Input:  nums=[1,2,3,4,4,3,2,1],n=4
Output: [1,4,2,3,3,2,4,1]
```

---

## Constraints

- `1 <= n <= 500`
- `nums.length == 2*n`
- `1 <= nums[i] <= 10^3`
