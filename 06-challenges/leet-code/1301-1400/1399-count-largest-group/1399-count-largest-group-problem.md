# 1399. Count Largest Group

[Problem Link](https://leetcode.com/problems/count-largest-group/)

## Description
Group numbers 1..n by digit sum. Return count of groups with the largest size.

## Examples
Input: n = 13 → 4 (groups by digit sum: 1→[1,10], 2→[2,11], 3→[3,12], 4→[4,13], 5→[5], 6→[6], 7→[7], 8→[8], 9→[9])

## Constraints
- 1 <= n <= 10^4
