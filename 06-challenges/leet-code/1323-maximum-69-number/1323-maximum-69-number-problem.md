# 1323. Maximum 69 Number

[Problem Link](https://leetcode.com/problems/maximum-69-number/)

## Description
Given positive integer num consisting only of digits 6 and 9, return the maximum number you can get by changing at most one digit (6→9 or 9→6).

## Examples
Input: num = 9669 → 9969

## Constraints
- 1 <= num <= 9999
