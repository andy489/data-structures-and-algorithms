# 1451. Rearrange Words In A Sentence

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/rearrange-words-in-a-sentence/

---

## Problem Statement

Rearrange words in `text` (first word starts with uppercase) sorted by increasing length. For equal lengths preserve original order. Return result with first word capitalized.

---

## Examples

**Example 1:**
```
Input:  text = "Leetcode is cool"
Output: "Is cool leetcode"
```

**Example 2:**
```
Input:  text = "Keep calm and move on"
Output: "on and keep move calm"
```

---

## Constraints

- `text begins with a capital letter`
- `1 <= text.length <= 10^9`
- `text does not contain leading/trailing spaces`
- `There is at most one space between two words`
