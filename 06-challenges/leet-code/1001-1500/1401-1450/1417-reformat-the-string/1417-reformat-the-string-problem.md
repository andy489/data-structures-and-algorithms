# 1417. Reformat The String

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/reformat-the-string/

---

## Problem Statement

Given alphanumeric string `s`, reformat it so that no two adjacent characters are of the same type (letter/digit). Return any valid reformatted string, or empty if impossible.

---

## Examples

**Example 1:**
```
Input:  s = "a0b1c2"
Output: "a0b1c2"
```

**Example 2:**
```
Input:  s = "leetcode"
Output: ""
```

**Example 3:**
```
Input:  s = "1229857369"
Output: ""
```

---

## Constraints

- `1 <= s.length <= 500`
- `s consists of only lowercase English letters and/or digits`
