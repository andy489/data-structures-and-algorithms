# 1457. Pseudo Palindromic Paths In A Binary Tree

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/pseudo-palindromic-paths-in-a-binary-tree/

---

## Problem Statement

Return the number of pseudo-palindromic paths from root to leaf (a path whose elements can be rearranged into a palindrome).

---

## Examples

**Example 1:**
```
Input:  root=[2,3,1,3,1,null,1]
Output: 2
```

**Example 2:**
```
Input:  root=[2,1,1,1,3,null,null,null,null,null,1]
Output: 1
```

**Example 3:**
```
Input:  root=[9]
Output: 1
```

---

## Constraints

- `The number of nodes in the tree is in [1, 10^5]`
- `1 <= Node.val <= 9`
