# 1405. Longest Happy String

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/longest-happy-string/

---

## Problem Statement

A string is happy if no three consecutive characters are the same. Given counts `a`, `b`, `c` of characters 'a', 'b', 'c', return any longest happy string.

---

## Examples

**Example 1:**
```
Input:  a=1,b=1,c=7
Output: "ccaccbcc"
```

**Example 2:**
```
Input:  a=7,b=1,c=0
Output: "aabaa"
```

---

## Constraints

- `0 <= a, b, c <= 100`
- `a + b + c > 0`
