# 1311. Get Watched Videos by Your Friends

[Problem Link](https://leetcode.com/problems/get-watched-videos-by-your-friends/)

## Description
Given watchedVideos, friends graph, id, and level k, return a list of videos watched by friends at exactly level k, sorted by frequency ascending then alphabetically.

## Examples
Input: watchedVideos = [["A","B"],["C"],["B","C"],["D"]], friends = [[1,2],[0,3],[0,3],[1,2]], id = 0, level = 2 → ["D"]

## Constraints
- 2 <= n <= 100
- 1 <= watchedVideos[i][j].length <= 8
