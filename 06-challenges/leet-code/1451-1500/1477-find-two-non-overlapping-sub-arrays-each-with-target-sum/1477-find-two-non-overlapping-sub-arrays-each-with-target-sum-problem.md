# 1477. Find Two Non Overlapping Sub Arrays Each With Target Sum

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/find-two-non-overlapping-sub-arrays-each-with-target-sum/

---

## Problem Statement

Return the minimum sum of lengths of two non-overlapping subarrays each with sum equal to target. Return -1 if impossible.

---

## Examples

**Example 1:**
```
Input:  arr=[3,2,2,4,3],target=3
Output: 2
```

**Example 2:**
```
Input:  arr=[7,3,4,7],target=7
Output: 2
```

**Example 3:**
```
Input:  arr=[4,3,2,6,2,3,4],target=6
Output: 3
```

---

## Constraints

- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 1000`
- `1 <= target <= 10^8`
