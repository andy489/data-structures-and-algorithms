# 1325. Delete Leaves With a Given Value

[Problem Link](https://leetcode.com/problems/delete-leaves-with-a-given-value/)

## Description
Given binary tree root and integer target, delete all leaf nodes with value target. Repeat until no more such leaves exist.

## Examples
Input: root = [1,2,3,2,null,2,4], target = 2 → [1,null,3,null,4]

## Constraints
- Number of nodes in [1, 3000]
