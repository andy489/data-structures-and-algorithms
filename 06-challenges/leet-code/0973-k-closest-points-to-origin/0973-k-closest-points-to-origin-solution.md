# 973. K Closest Points to Origin — Solution

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/k-closest-points-to-origin/

---

## Solution: Sort — O(n log n) time, O(1) space

**Idea:** Sort by squared distance and return first k points.

**Complexity:**

| | |
|---|---|
| Time | O(n log n) |
| Space | O(1) extra |
