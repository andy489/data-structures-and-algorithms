# 1391. Check if There is a Valid Path in a Grid

[Problem Link](https://leetcode.com/problems/check-if-there-is-a-valid-path-in-a-grid/)

## Description
Grid has 6 street types (like pipes). Return true if there's a valid path from (0,0) to (m-1,n-1).

## Examples
Input: grid = [[2,4,3],[6,5,2]] → true

## Constraints
- m == grid.length, n == grid[i].length
- 1 <= m, n <= 300
