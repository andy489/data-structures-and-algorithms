# 1389. Create Target Array in the Given Order

[Problem Link](https://leetcode.com/problems/create-target-array-in-the-given-order/)

## Description
Given arrays nums and index, insert nums[i] at position index[i] in target array (shifting elements). Return target.

## Examples
Input: nums=[0,1,2,3,4], index=[0,1,2,2,1] → [0,4,1,3,2]

## Constraints
- 1 <= nums.length, index.length <= 100
