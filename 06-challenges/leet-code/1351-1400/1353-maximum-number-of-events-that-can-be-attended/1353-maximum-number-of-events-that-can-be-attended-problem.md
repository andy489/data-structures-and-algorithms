# 1353. Maximum Number of Events That Can Be Attended

[Problem Link](https://leetcode.com/problems/maximum-number-of-events-that-can-be-attended/)

## Description
Given events [startDay, endDay], attend at most one event per day. Return max events you can attend.

## Examples
Input: events = [[1,2],[2,3],[3,4]] → 3

## Constraints
- 1 <= events.length <= 10^5
- 1 <= startDay <= endDay <= 10^5
