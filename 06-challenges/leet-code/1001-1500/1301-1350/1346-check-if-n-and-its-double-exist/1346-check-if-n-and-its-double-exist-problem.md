# 1346. Check If N and Its Double Exist

[Problem Link](https://leetcode.com/problems/check-if-n-and-its-double-exist/)

## Description
Given array arr, return true if there exist two indices i≠j such that arr[i] == 2*arr[j].

## Examples
Input: arr = [10,2,5,3] → true (10==2*5)

## Constraints
- 2 <= arr.length <= 500
- -10^3 <= arr[i] <= 10^3
