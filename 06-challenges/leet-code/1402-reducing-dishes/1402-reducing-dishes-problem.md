# 1402. Reducing Dishes

**Difficulty:** Hard
**Link:** https://leetcode.com/problems/reducing-dishes/

---

## Problem Statement

A chef has `satisfaction` levels for dishes. The like-time coefficient is `time[i] * satisfaction[i]`. Return the maximum sum of like-time coefficients achievable (dishes may be discarded).

---

## Examples

**Example 1:**
```
Input:  satisfaction = [-1,-8,0,5,-9]
Output: 14
```

**Example 2:**
```
Input:  satisfaction = [4,3,2]
Output: 20
```

**Example 3:**
```
Input:  satisfaction = [-1,-4,-5]
Output: 0
```

---

## Constraints

- `-10^3 <= satisfaction[i] <= 10^3`
- `1 <= satisfaction.length <= 500`
