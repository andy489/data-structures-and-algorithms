# 1312. Minimum Insertion Steps to Make a String Palindrome

[Problem Link](https://leetcode.com/problems/minimum-insertion-steps-to-make-a-string-palindrome/)

## Description
Given string s, return the minimum number of character insertions needed to make it a palindrome.

## Examples
Input: s = "zzazz" → 0
Input: s = "mbadm" → 2

## Constraints
- 1 <= s.length <= 500
