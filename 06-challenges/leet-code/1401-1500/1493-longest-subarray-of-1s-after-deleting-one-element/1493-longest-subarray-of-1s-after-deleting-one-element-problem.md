# 1493. Longest Subarray Of 1s After Deleting One Element

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/longest-subarray-of-1s-after-deleting-one-element/

---

## Problem Statement

Return length of longest subarray of 1s after deleting exactly one element from a binary array.

---

## Examples

**Example 1:**
```
Input:  nums=[1,1,0,1]
Output: 3
```

**Example 2:**
```
Input:  nums=[0,1,1,1,0,1,1,0,1]
Output: 5
```

**Example 3:**
```
Input:  nums=[1,1,1]
Output: 2
```

---

## Constraints

- `1 <= nums.length <= 10^5`
- `nums[i] is 0 or 1`
