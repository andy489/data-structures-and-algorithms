# 1196. How Many Apples Can You Put into the Basket

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/how-many-apples-can-you-put-into-the-basket/

---

## Problem Statement

You have some apples and a basket that can carry up to `5000` units of weight.

Given an integer array `weight` where `weight[i]` is the weight of the `i`th apple, return the maximum number of apples you can put in the basket.

---

## Examples

**Example 1:**
```
Input:  weight = [100,200,150,1000]
Output: 4
```

**Example 2:**
```
Input:  weight = [900,950,800,1000,700,800]
Output: 5
```

---

## Constraints

- `1 <= weight.length <= 10^3`
- `1 <= weight[i] <= 10^3`
