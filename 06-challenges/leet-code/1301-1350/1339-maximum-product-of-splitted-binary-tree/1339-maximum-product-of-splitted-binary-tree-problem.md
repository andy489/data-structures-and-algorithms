# 1339. Maximum Product of Splitted Binary Tree

[Problem Link](https://leetcode.com/problems/maximum-product-of-splitted-binary-tree/)

## Description
Given binary tree, remove one edge to split into two subtrees. Return maximum product of the two subtree sums, mod 10^9+7.

## Examples
Input: root = [1,2,3,4,5,6] → 110

## Constraints
- Number of nodes in [2, 50000]
- 1 <= Node.val <= 10^4
