# 1201. Ugly Number III

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/ugly-number-iii/

---

## Problem Statement

Given three integers `n`, `a`, and `b`, return the `n`-th ugly number.

Ugly numbers are positive integers divisible by `a` or `b`.

---

## Examples

**Example 1:**
```
Input:  n = 3, a = 2, b = 3
Output: 4
```

---

## Constraints

- `1 <= n, a, b <= 10^9`
- `1 <= n <= 10^9`
