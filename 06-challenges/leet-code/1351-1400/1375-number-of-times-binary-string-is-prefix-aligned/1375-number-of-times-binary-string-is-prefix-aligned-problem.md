# 1375. Number of Times Binary String Is Prefix-Aligned

[Problem Link](https://leetcode.com/problems/number-of-times-binary-string-is-prefix-aligned/)

## Description
You have a binary string of n zeros. flips[i] flips bit at position flips[i] (1-indexed). Count steps where string is "prefix-aligned" (all 1s from index 0 to some point).

## Examples
Input: flips = [3,2,4,1,5] → 2

## Constraints
- n == flips.length
- 1 <= n <= 5 * 10^4
