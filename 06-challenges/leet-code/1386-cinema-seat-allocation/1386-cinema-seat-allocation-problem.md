# 1386. Cinema Seat Allocation

[Problem Link](https://leetcode.com/problems/cinema-seat-allocation/)

## Description
Cinema with n rows, 10 seats (1-10). Groups of 4 sit together (seats 2-5, 4-7, or 6-9). Given reserved seats, return max 4-person groups accommodated.

## Examples
Input: n=3, reservedSeats=[[1,2],[1,3],[1,8],[2,6],[3,1],[3,10]] → 4

## Constraints
- 1 <= n <= 10^9
- 1 <= reservedSeats.length <= min(10*n, 10^4)
