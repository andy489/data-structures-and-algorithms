# 1377. Frog Position After T Seconds

[Problem Link](https://leetcode.com/problems/frog-position-after-t-seconds/)

## Description
Frog starts at vertex 1 of a tree. Each second it jumps to an unvisited adjacent vertex with equal probability. After t seconds, return probability of being at target.

## Examples
Input: n=7, edges=[[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t=2, target=4 → 0.16667

## Constraints
- 1 <= n <= 100
