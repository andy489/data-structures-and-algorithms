# 1368. Minimum Cost to Make at Least One Valid Path in a Grid

[Problem Link](https://leetcode.com/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/)

## Description
Given m×n grid where each cell has a direction (1=right,2=left,3=down,4=up), cost 0 to follow arrow, 1 to change it. Return min cost path from (0,0) to (m-1,n-1).

## Examples
Input: grid = [[1,1,1,1],[2,2,2,2],[1,1,1,1],[2,2,2,2]] → 3

## Constraints
- m == grid.length, n == grid[i].length
- 1 <= m, n <= 100
