# 1390. Four Divisors

[Problem Link](https://leetcode.com/problems/four-divisors/)

## Description
Given array nums, return sum of all integers that have exactly 4 divisors.

## Examples
Input: nums = [21,4,7] → 32 (21: 1,3,7,21 → sum=32; 4: 1,2,4; 7: 1,7)

## Constraints
- 1 <= nums.length <= 10^4
- 1 <= nums[i] <= 10^5
