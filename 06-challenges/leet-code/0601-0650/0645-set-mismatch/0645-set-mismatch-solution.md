# 645. Set Mismatch — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/set-mismatch/

---

## Solution: Frequency Count — O(n) time, O(n) space

**Idea:** Count frequencies; the number with count 2 is the duplicate, the number with count 0 is the missing one.

**Complexity:**

| | |
|---|---|
| Time | O(n) |
| Space | O(n) — frequency array |
