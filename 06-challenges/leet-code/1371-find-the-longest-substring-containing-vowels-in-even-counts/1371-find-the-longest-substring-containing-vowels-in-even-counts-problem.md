# 1371. Find the Longest Substring Containing Vowels in Even Counts

[Problem Link](https://leetcode.com/problems/find-the-longest-substring-containing-vowels-in-even-counts/)

## Description
Return the size of the longest substring containing each vowel an even number of times.

## Examples
Input: s = "eleetminicoworoep" → 13

## Constraints
- 1 <= s.length <= 5 * 10^5
