# 1316. Distinct Echo Substrings

[Problem Link](https://leetcode.com/problems/distinct-echo-substrings/)

## Description
Return the number of distinct non-empty substrings of text that can be written as the concatenation of some string with itself (i.e., "abab" = "ab"+"ab").

## Examples
Input: text = "abcabcabc" → 3 ("abcabc","bcabca","cabcab")

## Constraints
- 1 <= text.length <= 2000
