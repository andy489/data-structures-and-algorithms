# 1174. Immediate Food Delivery II

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/immediate-food-delivery-ii/

---

## Problem Statement

Table `Delivery`: (delivery_id, customer_id, order_date, customer_pref_delivery_date).

If the customer's preferred delivery date is the same as the order date, then the order is called immediate; otherwise, it is scheduled. Find the percentage of immediate orders in the first orders of each customer, rounded to 2 decimal places.
