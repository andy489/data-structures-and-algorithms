# 1310. XOR Queries of a Subarray

[Problem Link](https://leetcode.com/problems/xor-queries-of-a-subarray/)

## Description
Given array arr and queries [L, R], return XOR of arr[L]...arr[R] for each query.

## Examples
Input: arr = [1,3,4,8], queries = [[0,1],[1,2],[0,3],[3,3]] → [2,7,14,8]

## Constraints
- 1 <= arr.length, queries.length <= 3 * 10^4
- 1 <= arr[i] <= 10^9
