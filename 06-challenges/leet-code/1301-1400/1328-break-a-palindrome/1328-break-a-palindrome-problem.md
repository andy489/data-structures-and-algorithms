# 1328. Break a Palindrome

[Problem Link](https://leetcode.com/problems/break-a-palindrome/)

## Description
Given palindromic string palindrome, replace exactly one character to make it lexicographically smallest non-palindrome, or return "" if impossible.

## Examples
Input: palindrome = "abccba" → "aaccba"

## Constraints
- 1 <= palindrome.length <= 1000
