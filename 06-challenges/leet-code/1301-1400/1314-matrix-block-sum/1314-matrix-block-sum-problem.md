# 1314. Matrix Block Sum

[Problem Link](https://leetcode.com/problems/matrix-block-sum/)

## Description
Given matrix mat and integer k, return matrix answer where answer[i][j] is the sum of all mat[r][c] with i-k<=r<=i+k and j-k<=c<=j+k.

## Examples
Input: mat = [[1,2,3],[4,5,6],[7,8,9]], k = 1 → [[12,21,16],[27,45,33],[24,39,28]]

## Constraints
- m == mat.length, n == mat[i].length
- 1 <= m, n, k <= 100
