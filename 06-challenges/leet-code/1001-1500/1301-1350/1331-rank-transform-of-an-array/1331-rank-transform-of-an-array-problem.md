# 1331. Rank Transform of an Array

[Problem Link](https://leetcode.com/problems/rank-transform-of-an-array/)

## Description
Replace each element of arr with its rank. Rank is an integer starting from 1, assigned in ascending order, equal elements get the same rank.

## Examples
Input: arr = [40,10,20,30] → [4,1,2,3]

## Constraints
- 0 <= arr.length <= 10^5
- -10^9 <= arr[i] <= 10^9
