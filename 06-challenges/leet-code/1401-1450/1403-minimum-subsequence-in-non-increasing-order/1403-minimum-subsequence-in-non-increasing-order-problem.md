# 1403. Minimum Subsequence In Non Increasing Order

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/minimum-subsequence-in-non-increasing-order/

---

## Problem Statement

Return the minimum-length subsequence (non-increasing) with sum strictly greater than the remaining elements' sum.

---

## Examples

**Example 1:**
```
Input:  nums = [4,3,10,9,8]
Output: [10,9]
```

**Example 2:**
```
Input:  nums = [4,4,7,6,7]
Output: [7,7,6]
```

---

## Constraints

- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^3`
