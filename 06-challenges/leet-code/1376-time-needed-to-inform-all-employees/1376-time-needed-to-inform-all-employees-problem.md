# 1376. Time Needed to Inform All Employees

[Problem Link](https://leetcode.com/problems/time-needed-to-inform-all-employees/)

## Description
Given company tree (manager, informTime), find total time to inform all employees starting from headID.

## Examples
Input: n=6, headID=2, manager=[-1,2,2,2,2,2], informTime=[0,0,10,0,0,0] → 10

## Constraints
- 1 <= n <= 10^5
