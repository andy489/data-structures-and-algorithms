# 1356. Sort Integers by The Number of 1 Bits

[Problem Link](https://leetcode.com/problems/sort-integers-by-the-number-of-1-bits/)

## Description
Sort arr in ascending order by number of 1-bits in binary representation. Ties broken by value ascending.

## Examples
Input: arr = [0,1,2,3,4,5,6,7,8] → [0,1,2,4,8,3,5,6,7]

## Constraints
- 1 <= arr.length <= 500
