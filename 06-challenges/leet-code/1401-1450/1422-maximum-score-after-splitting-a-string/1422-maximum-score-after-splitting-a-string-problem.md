# 1422. Maximum Score After Splitting A String

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/maximum-score-after-splitting-a-string/

---

## Problem Statement

Return the maximum score of splitting string `s` into two non-empty substrings. Score = #zeros in left + #ones in right.

---

## Examples

**Example 1:**
```
Input:  s = "011101"
Output: 5
```

**Example 2:**
```
Input:  s = "00111"
Output: 5
```

**Example 3:**
```
Input:  s = "1111"
Output: 3
```

---

## Constraints

- `2 <= s.length <= 500`
- `s consists only of '0' and '1'`
