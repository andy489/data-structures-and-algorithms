# 1461. Check If A String Contains All Binary Codes Of Size K

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/check-if-a-string-contains-all-binary-codes-of-size-k/

---

## Problem Statement

Return true if `s` contains all binary codes of length `k` as substrings.

---

## Examples

**Example 1:**
```
Input:  s="00110110",k=2
Output: true
```

**Example 2:**
```
Input:  s="0110",k=1
Output: true
```

**Example 3:**
```
Input:  s="0110",k=2
Output: false
```

---

## Constraints

- `1 <= s.length <= 5*10^5`
- `1 <= k <= 20`
- `s consists only of '0' and '1'`
