# 1359. Count All Valid Pickup and Delivery Options

[Problem Link](https://leetcode.com/problems/count-all-valid-pickup-and-delivery-options/)

## Description
Given n orders, each with a pickup P_i and delivery D_i where P_i must come before D_i, count all valid sequences of 2n events, mod 10^9+7.

## Examples
Input: n = 1 → 1
Input: n = 2 → 6

## Constraints
- 1 <= n <= 500
