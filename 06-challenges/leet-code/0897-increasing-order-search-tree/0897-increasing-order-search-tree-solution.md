# 897. Increasing Order Search Tree — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/increasing-order-search-tree/

---

## Solution: In-Order DFS — O(n) time, O(n) space

**Idea:** In-order traversal yields sorted values. Rebuild as right-only chain.

**Complexity:**

| | |
|---|---|
| Time | O(n) |
| Space | O(n) — recursion |
