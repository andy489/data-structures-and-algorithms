# 1496. Path Crossing

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/path-crossing/

---

## Problem Statement

Given directions string, return true if the path crosses itself at any point.

---

## Examples

**Example 1:**
```
Input:  path="NES"
Output: false
```

**Example 2:**
```
Input:  path="NESWW"
Output: true
```

---

## Constraints

- `1 <= path.length <= 10^4`
- `path[i] is 'N', 'S', 'E', or 'W'`
