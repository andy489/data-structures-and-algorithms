# 1326. Minimum Number of Taps to Open to Water a Garden

[Problem Link](https://leetcode.com/problems/minimum-number-of-taps-to-open-to-water-a-garden/)

## Description
There are n+1 taps at positions 0..n. Tap i can water [i-ranges[i], i+ranges[i]]. Return min taps to water [0,n], or -1 if impossible.

## Examples
Input: n = 5, ranges = [3,4,1,1,0,0] → 1

## Constraints
- 1 <= n <= 10^4
