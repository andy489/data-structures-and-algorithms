# 1400. Construct K Palindrome Strings

[Problem Link](https://leetcode.com/problems/construct-k-palindrome-strings/)

## Description
Given string s and k, return true if we can use all characters of s to construct k palindrome strings.

## Examples
Input: s = "annabelle", k = 2 → true

## Constraints
- 1 <= s.length <= 10^5
- 1 <= k <= 10^5
