# 1365. How Many Numbers Are Smaller Than the Current Number

[Problem Link](https://leetcode.com/problems/how-many-numbers-are-smaller-than-the-current-number/)

## Description
For each element of nums, count how many other elements are smaller.

## Examples
Input: nums = [8,1,2,2,3] → [4,0,1,1,3]

## Constraints
- 2 <= nums.length <= 500
- 0 <= nums[i] <= 100
