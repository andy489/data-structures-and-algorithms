# 1224. Maximum Equal Frequency

**Difficulty:** Hard
**Link:** https://leetcode.com/problems/maximum-equal-frequency/

---

## Problem Statement

Given an array `nums` of positive integers, return the longest prefix of `nums` such that it's possible to remove exactly one element from this prefix so that every remaining number appears the same number of times.

---

## Examples

**Example 1:**
```
Input:  nums = [2,2,1,1,5,3,3,5]
Output: 7
```

---

## Constraints

- `2 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
