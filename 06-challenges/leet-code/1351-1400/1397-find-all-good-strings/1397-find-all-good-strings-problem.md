# 1397. Find All Good Strings

[Problem Link](https://leetcode.com/problems/find-all-good-strings/)

## Description
Given s1, s2 (lowercase, same length), and evil string, return count of strings s in [s1,s2] that do not contain evil as substring, mod 10^9+7.

## Examples
Input: n=2, s1="aa", s2="da", evil="b" → 51

## Constraints
- s1.length == s2.length == n
- 1 <= n <= 500
- 1 <= evil.length <= 50
