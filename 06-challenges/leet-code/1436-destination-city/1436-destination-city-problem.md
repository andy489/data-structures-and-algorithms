# 1436. Destination City

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/destination-city/

---

## Problem Statement

Given paths where paths[i]=[cityA,cityB], find the destination city — the city that has no outgoing path.

---

## Examples

**Example 1:**
```
Input:  paths=[["London","New York"],["New York","Lima"],["Lima","Sao Paulo"]]
Output: "Sao Paulo"
```

---

## Constraints

- `1 <= paths.length <= 100`
- `paths[i].length == 2`
- `1 <= cityA.length,cityB.length <= 10`
