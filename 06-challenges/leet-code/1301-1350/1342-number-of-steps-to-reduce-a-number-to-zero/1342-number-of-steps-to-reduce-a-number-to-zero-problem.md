# 1342. Number of Steps to Reduce a Number to Zero

[Problem Link](https://leetcode.com/problems/number-of-steps-to-reduce-a-number-to-zero/)

## Description
Given integer num, return the number of steps to reduce it to zero. If even, divide by 2; if odd, subtract 1.

## Examples
Input: num = 14 → 6

## Constraints
- 0 <= num <= 10^6
