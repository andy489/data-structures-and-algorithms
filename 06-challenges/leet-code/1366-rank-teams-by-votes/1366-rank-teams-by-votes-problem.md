# 1366. Rank Teams by Votes

[Problem Link](https://leetcode.com/problems/rank-teams-by-votes/)

## Description
Given votes strings, rank teams by votes in each position (1st place, then 2nd, etc.); ties broken alphabetically.

## Examples
Input: votes = ["ABC","ACB","ABC","ACB","ACB"] → "ACB"

## Constraints
- 1 <= votes.length <= 1000
- 1 <= votes[i].length <= 26
