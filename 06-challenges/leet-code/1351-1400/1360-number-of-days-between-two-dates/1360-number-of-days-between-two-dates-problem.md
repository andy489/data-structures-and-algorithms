# 1360. Number of Days Between Two Dates

[Problem Link](https://leetcode.com/problems/number-of-days-between-two-dates/)

## Description
Given two dates as strings "YYYY-MM-DD", return the absolute difference in days.

## Examples
Input: date1 = "2019-06-29", date2 = "2019-06-30" → 1

## Constraints
- Dates are between 1971-01-01 and 2100-12-31
