# 2048. Next Greater Numerically Balanced Number

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/next-greater-numerically-balanced-number/

---

## Problem Statement

A number is **numerically balanced** if for every digit `d` in `n`, there are exactly `d` occurrences of `d` in `n`. Given `n`, return the smallest numerically balanced number **strictly greater** than `n`.

---

## Examples

**Example 1:**
```
Input:  n = 1
Output: 22
```
Explanation: 22 has two 2's.

**Example 2:**
```
Input:  n = 1000
Output: 1333
```

**Example 3:**
```
Input:  n = 3000
Output: 3133
```

---

## Constraints

- `0 <= n <= 10^6`
