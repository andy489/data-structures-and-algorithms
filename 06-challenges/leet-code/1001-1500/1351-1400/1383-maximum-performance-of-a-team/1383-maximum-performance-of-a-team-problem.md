# 1383. Maximum Performance of a Team

[Problem Link](https://leetcode.com/problems/maximum-performance-of-a-team/)

## Description
Given n engineers, speed array, efficiency array, and k (max team size), maximize performance = sum(speed) * min(efficiency). Return result mod 10^9+7.

## Examples
Input: n=6, speed=[2,10,3,1,5,8], efficiency=[5,4,3,9,7,2], k=2 → 60

## Constraints
- 1 <= n <= 10^5
- 1 <= k <= n
