# 1382. Balance a Binary Search Tree

[Problem Link](https://leetcode.com/problems/balance-a-binary-search-tree/)

## Description
Given BST, return a balanced BST with same node values.

## Examples
Input: root = [1,null,2,null,3,null,4,null,null] → [2,1,3,null,null,null,4] (or similar)

## Constraints
- Number of nodes in [1, 10^4]
- 1 <= Node.val <= 10^5
