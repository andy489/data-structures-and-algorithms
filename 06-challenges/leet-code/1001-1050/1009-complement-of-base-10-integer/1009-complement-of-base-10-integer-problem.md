# 1009. Complement of Base 10 Integer

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/complement-of-base-10-integer/

---

## Problem Statement

The complement of an integer is the integer you get when you flip all the `0`-bits to `1`-bits and all the `1`-bits to `0`-bits.

Given an integer `n`, return its complement.

---

## Examples

**Example 1:**
```
Input:  n = 5
Output: 2
Explanation: 5 is "101" in binary, complement is "010" = 2.
```

**Example 2:**
```
Input:  n = 7
Output: 0
```

---

## Constraints

- `0 <= n < 10^9`
