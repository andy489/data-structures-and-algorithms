# Solution: 3423. Maximum Difference Between Adjacent Elements in a Circular Array

**Link:** https://leetcode.com/problems/maximum-difference-between-adjacent-elements-in-a-circular-array/

## Approach

Simple linear scan. Check all adjacent pairs including the wrap-around pair (last, first). Track the maximum absolute difference.

## Complexity

- Time: O(n)
- Space: O(1)
