# 1307. Verbal Arithmetic Puzzle

[Problem Link](https://leetcode.com/problems/verbal-arithmetic-puzzle/)

## Description
Given words and result, return true if the equation words[0] + words[1] + ... = result can be satisfied by assigning digits 0–9 to letters (no leading zeros, bijective mapping).

## Examples
Input: words = ["SEND","MORE"], result = "MONEY" → true (S=9,E=5,N=6,D=7,M=1,O=0,R=8,Y=2)

## Constraints
- 2 <= words.length <= 5
- 1 <= words[i].length, result.length <= 7
- All letters uppercase, at most 10 unique letters
