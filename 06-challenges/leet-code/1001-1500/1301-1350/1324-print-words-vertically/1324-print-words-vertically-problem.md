# 1324. Print Words Vertically

[Problem Link](https://leetcode.com/problems/print-words-vertically/)

## Description
Given string s, print words vertically. Each row in the result is a column of characters from the words, padded with spaces on the right if needed (but no trailing spaces).

## Examples
Input: s = "HOW ARE YOU" → ["HAY","ORO","WEU"]

## Constraints
- 1 <= s.length <= 200
