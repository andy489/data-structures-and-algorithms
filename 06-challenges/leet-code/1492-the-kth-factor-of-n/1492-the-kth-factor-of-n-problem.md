# 1492. The Kth Factor Of N

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/the-kth-factor-of-n/

---

## Problem Statement

Return the k-th factor of n in increasing order. Return -1 if fewer than k factors.

---

## Examples

**Example 1:**
```
Input:  n=12,k=3
Output: 3
```

**Example 2:**
```
Input:  n=7,k=2
Output: 7
```

**Example 3:**
```
Input:  n=4,k=4
Output: -1
```

---

## Constraints

- `1 <= k <= n <= 1000`
