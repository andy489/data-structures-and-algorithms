# 1370. Increasing Decreasing String

[Problem Link](https://leetcode.com/problems/increasing-decreasing-string/)

## Description
Given string s, repeatedly pick smallest remaining char (append), then largest remaining (append), alternating. Return result.

## Examples
Input: s = "aaaabbbbcccc" → "abccbaabccba"

## Constraints
- 1 <= s.length <= 500
