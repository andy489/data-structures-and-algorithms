# 1363. Largest Multiple of Three

[Problem Link](https://leetcode.com/problems/largest-multiple-of-three/)

## Description
Given digits array, return the largest multiple of three that can be formed, or "" if impossible.

## Examples
Input: digits = [8,1,9] → "981"

## Constraints
- 1 <= digits.length <= 10^4
- 0 <= digits[i] <= 9
