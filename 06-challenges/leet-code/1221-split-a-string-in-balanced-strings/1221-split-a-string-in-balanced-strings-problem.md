# 1221. Split a String in Balanced Strings

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/split-a-string-in-balanced-strings/

---

## Problem Statement

Balanced strings are those that have an equal quantity of `'L'` and `'R'` characters.

Given a balanced string `s`, split it into some number of substrings such that each substring is balanced. Return the maximum number of balanced substrings you can obtain.

---

## Examples

**Example 1:**
```
Input:  s = "RLRRLLRLRL"
Output: 4
```

---

## Constraints

- `2 <= s.length <= 1000`
- `s[i] is either 'L' or 'R'`
- `s is a balanced string`
