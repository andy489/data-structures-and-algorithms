# 1340. Jump Game V

[Problem Link](https://leetcode.com/problems/jump-game-v/)

## Description
Given array arr and integer d, from index i you can jump to any j where |i-j|<=d and all values between i and j are strictly less than arr[i]. Return max number of indices you can visit.

## Examples
Input: arr = [6,4,14,6,8,13,9,7,10,6,12], d = 2 → 4

## Constraints
- 1 <= arr.length <= 1000
- 1 <= d <= arr.length
