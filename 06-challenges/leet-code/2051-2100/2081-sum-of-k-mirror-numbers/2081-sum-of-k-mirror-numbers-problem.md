# 2081. Sum of K-Mirror Numbers

**Difficulty:** Hard
**Link:** https://leetcode.com/problems/sum-of-k-mirror-numbers/

---

## Problem Statement

A **k-mirror number** is a positive integer that reads the same forwards and backwards in both base-10 and base-k. Find the sum of the first `n` k-mirror numbers.

---

## Examples

**Example 1:**
```
Input:  k = 2, n = 5
Output: 25
```
Explanation: 1,3,5,7,9 are the first 5 2-mirror numbers.

**Example 2:**
```
Input:  k = 3, n = 7
Output: 499
```

**Example 3:**
```
Input:  k = 7, n = 17
Output: 20379000
```

---

## Constraints

- `2 <= k <= 9`
- `1 <= n <= 30`
