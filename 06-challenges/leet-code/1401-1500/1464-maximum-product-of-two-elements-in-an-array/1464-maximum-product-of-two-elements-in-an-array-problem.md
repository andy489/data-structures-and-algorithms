# 1464. Maximum Product Of Two Elements In An Array

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/maximum-product-of-two-elements-in-an-array/

---

## Problem Statement

Return the maximum value of `(nums[i]-1)*(nums[j]-1)` where `i != j`.

---

## Examples

**Example 1:**
```
Input:  nums=[3,4,5,2]
Output: 12
```

**Example 2:**
```
Input:  nums=[1,5,4,5]
Output: 16
```

**Example 3:**
```
Input:  nums=[3,7]
Output: 12
```

---

## Constraints

- `2 <= nums.length <= 500`
- `1 <= nums[i] <= 10^3`
