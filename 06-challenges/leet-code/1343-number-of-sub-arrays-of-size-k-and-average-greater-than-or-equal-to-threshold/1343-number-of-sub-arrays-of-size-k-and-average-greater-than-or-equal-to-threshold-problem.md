# 1343. Number of Sub-arrays of Size K and Average Greater than or Equal to Threshold

[Problem Link](https://leetcode.com/problems/number-of-sub-arrays-of-size-k-and-average-greater-than-or-equal-to-threshold/)

## Description
Return the number of subarrays of length k with average >= threshold.

## Examples
Input: arr = [2,2,2,2,5,5,5,8], k = 3, threshold = 4 → 3

## Constraints
- 1 <= arr.length <= 10^5
