# 1313. Decompress Run-Length Encoded List

[Problem Link](https://leetcode.com/problems/decompress-run-length-encoded-list/)

## Description
Given array nums encoded as [freq1, val1, freq2, val2, ...], return the decompressed array.

## Examples
Input: nums = [1,2,3,4] → [2,4,4,4]

## Constraints
- 2 <= nums.length <= 100
- nums.length % 2 == 0
