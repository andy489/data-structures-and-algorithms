# 1319. Number of Operations to Make Network Connected

[Problem Link](https://leetcode.com/problems/number-of-operations-to-make-network-connected/)

## Description
Given n computers and connections, return the minimum number of cable reconnections to make all computers connected, or -1 if impossible.

## Examples
Input: n = 4, connections = [[0,1],[0,2],[1,2]] → 1

## Constraints
- 1 <= n <= 10^5
- 1 <= connections.length <= min(n*(n-1)/2, 10^5)
