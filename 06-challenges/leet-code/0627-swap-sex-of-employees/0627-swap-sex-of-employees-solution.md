# 627. Swap Salary — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/swap-salary/

---

## Solution: UPDATE with IF — O(n) time, O(1) space

**Idea:** A single UPDATE with an IF expression (or CASE) swaps 'm' ↔ 'f' in one pass with no temp tables.

**Complexity:**

| | |
|---|---|
| Time | O(n) — update every row |
| Space | O(1) — in-place update |
