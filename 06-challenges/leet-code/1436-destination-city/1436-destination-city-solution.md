# 1436. Destination City — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/destination-city/

---

## Solution: HashSet — O(n) time, O(n) space

**Idea:** Put all source cities in a set. Return the destination city not in the set.

**Algorithm:**
1. Collect all source cities.
2. Find the destination city not in the source set.

**Complexity:**

| | |
|---|---|
| Time | O(n) |
| Space | O(n) |
