# 1453. Maximum Number Of Darts Inside Of A Circular Dartboard

**Difficulty:** Hard
**Link:** https://leetcode.com/problems/maximum-number-of-darts-inside-of-a-circular-dartboard/

---

## Problem Statement

Return the maximum number of darts inside or on a circle of radius `r`. Points are given as `darts`.

---

## Examples

**Example 1:**
```
Input:  darts=[[-2,0],[2,0],[0,2],[0,-2]],r=2
Output: 4
```

**Example 2:**
```
Input:  darts=[[-3,0],[3,0],[2,1],[3,1]],r=3
Output: 3
```

---

## Constraints

- `('1 <= darts.length <= 100', '-10^4 <= darts[i][0], darts[i][1] <= 10^4', 'All darts are unique', '1 <= r <= 5000')`
