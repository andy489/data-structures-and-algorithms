# 1392. Longest Happy Prefix

[Problem Link](https://leetcode.com/problems/longest-happy-prefix/)

## Description
A string s is a "happy prefix" if it's both a prefix and suffix of s (not equal to s itself). Return the longest such happy prefix, or "" if none.

## Examples
Input: s = "level" → "l"
Input: s = "ababab" → "abab"

## Constraints
- 1 <= s.length <= 10^5
