# 1338. Reduce Array Size to The Half

[Problem Link](https://leetcode.com/problems/reduce-array-size-to-the-half/)

## Description
Given array arr, choose a set of integers and remove all occurrences. Return the minimum size of the set to remove at least half of the integers.

## Examples
Input: arr = [3,3,3,3,5,5,5,2,2,7] → 2

## Constraints
- 2 <= arr.length <= 10^5
- arr.length is even
