# 1406. Stone Game Iii

**Difficulty:** Hard
**Link:** https://leetcode.com/problems/stone-game-iii/

---

## Problem Statement

Alice and Bob take turns (Alice first) taking 1, 2, or 3 stones from the left of an array `stoneValue`. They play optimally. Return `"Alice"`, `"Bob"`, or `"Tie"`.

---

## Examples

**Example 1:**
```
Input:  stoneValue = [1,2,3,7]
Output: "Bob"
```

**Example 2:**
```
Input:  stoneValue = [1,2,3,-9]
Output: "Alice"
```

**Example 3:**
```
Input:  stoneValue = [1,2,3,6]
Output: "Tie"
```

---

## Constraints

- `1 <= stoneValue.length <= 5*10^4`
- `-1000 <= stoneValue[i] <= 1000`
