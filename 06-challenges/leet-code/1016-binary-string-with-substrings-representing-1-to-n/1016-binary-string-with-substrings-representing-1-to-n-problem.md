# 1016. Binary String With Substrings Representing 1 To N

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/binary-string-with-substrings-representing-1-to-n/

---

## Problem Statement

Given a binary string `s` and a positive integer `n`, return `true` if the binary representations of all integers in the range `[1, n]` are substrings of `s`, or `false` otherwise.

---

## Examples

**Example 1:**
```
Input:  s = "0110", n = 3
Output: true
```

**Example 2:**
```
Input:  s = "0110", n = 4
Output: false
```

---

## Constraints

- `1 <= s.length <= 1000`
- `1 <= n <= 10^9`
