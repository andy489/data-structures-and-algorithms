# 1321. Restaurant Growth

[Problem Link](https://leetcode.com/problems/restaurant-growth/)

## Description
Given Customer table with customer_id, name, visited_on, amount, compute the moving average of 7-day window sum for each day (from day 7 onward).

## Examples
Output columns: visited_on, amount (sum of 7 days), average_amount

## Constraints
- SQL problem
