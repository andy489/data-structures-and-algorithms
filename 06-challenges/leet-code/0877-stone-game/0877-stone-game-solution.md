# 877. Stone Game — Solution

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/stone-game/

## Solution: Math — O(1) time, O(1) space

**Idea:** Alice always wins because she picks first and can always pick the larger of "even-indexed" or "odd-indexed" pile sets. With an even number of piles, Alice can always control which set she picks.

**Algorithm:**
