# 1387. Sort Integers by The Power Value

[Problem Link](https://leetcode.com/problems/sort-integers-by-the-power-value/)

## Description
Power value of x: steps in Collatz sequence to reach 1. Sort integers [lo, hi] by power, ties by value. Return kth element.

## Examples
Input: lo=12, hi=15, k=2 → 13

## Constraints
- 1 <= lo <= hi <= 1000
- 1 <= k <= hi - lo + 1
