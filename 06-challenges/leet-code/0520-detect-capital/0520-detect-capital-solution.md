# 520. Detect Capital — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/detect-capital/

---

## Solution: Count uppercase letters — O(n) time, O(1) space

**Idea:** Count uppercase letters. Valid if: all are uppercase, none are uppercase, or exactly the first is uppercase.

**Complexity:**

| | |
|---|---|
| Time | O(n) |
| Space | O(1) |
