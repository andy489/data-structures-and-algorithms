# 1306. Jump Game III

[Problem Link](https://leetcode.com/problems/jump-game-iii/)

## Description
Given an array arr and start index, you can jump from index i to i+arr[i] or i-arr[i]. Return true if you can reach any index with value 0.

## Examples
Input: arr = [4,2,3,0,3,1,2], start = 5 → true

## Constraints
- 1 <= arr.length <= 5 * 10^4
- 0 <= arr[i] < arr.length
- 0 <= start < arr.length
