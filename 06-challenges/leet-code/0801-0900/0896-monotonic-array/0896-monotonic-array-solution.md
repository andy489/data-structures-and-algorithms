# 896. Monotonic Array — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/monotonic-array/

---

## Solution: Single Pass — O(n) time, O(1) space

**Idea:** Track if we ever see an increase and if we ever see a decrease. If both happen, not monotonic.

**Complexity:**

| | |
|---|---|
| Time | O(n) |
| Space | O(1) |
