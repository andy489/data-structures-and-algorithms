# 949. Largest Time for Given Digits — Solution

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/largest-time-for-given-digits/

---

## Solution: Try All Permutations — O(1) time, O(1) space

**Idea:** Only 24 permutations of 4 digits. Try all, keep the largest valid time.

**Complexity:**

| | |
|---|---|
| Time | O(4!) = O(1) |
| Space | O(1) |
