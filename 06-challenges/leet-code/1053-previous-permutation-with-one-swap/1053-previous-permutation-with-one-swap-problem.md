# 1053. Previous Permutation With One Swap

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/previous-permutation-with-one-swap/

---

## Problem Statement

Given an array of positive integers `arr`, return the **lexicographically largest** permutation that is smaller than `arr`, that can be made with exactly one swap. If it cannot be done, then return the same array.

---

## Examples

**Example 1:**
```
Input:  arr = [3,2,1]
Output: [3,1,2]
```

**Example 2:**
```
Input:  arr = [1,1,5]
Output: [1,1,5]
```

---

## Constraints

- `1 <= arr.length <= 10^4`
- `1 <= arr[i] <= 10^4`
