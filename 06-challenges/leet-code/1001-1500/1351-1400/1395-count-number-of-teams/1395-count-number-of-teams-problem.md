# 1395. Count Number of Teams

[Problem Link](https://leetcode.com/problems/count-number-of-teams/)

## Description
Given soldiers with ratings, count the number of teams (i,j,k) where i<j<k and ratings are strictly increasing or strictly decreasing.

## Examples
Input: rating = [2,5,3,4,1] → 3

## Constraints
- n == rating.length
- 2 <= n <= 1000
