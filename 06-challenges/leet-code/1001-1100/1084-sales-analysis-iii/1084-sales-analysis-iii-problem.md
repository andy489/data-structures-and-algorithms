# 1084. Sales Analysis III

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/sales-analysis-iii/

---

## Problem Statement

Table `Product`: (product_id, product_name, unit_price). Table `Sales`: (seller_id, product_id, buyer_id, sale_date, quantity, price).

Write a solution to report the products that were only sold in the first quarter of 2019 (between 2019-01-01 and 2019-03-31 inclusive).
