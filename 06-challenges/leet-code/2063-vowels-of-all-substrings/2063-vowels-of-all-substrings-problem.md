# 2063. Vowels of All Substrings

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/vowels-of-all-substrings/

---

## Problem Statement

Given a string `word`, return the sum of the number of vowels in every substring of `word`.

---

## Examples

**Example 1:**
```
Input:  word = "aba"
Output: 6
```
Explanation: Substrings: a,ab,aba,b,ba,a. Vowels: 1+1+2+0+1+1=6.

**Example 2:**
```
Input:  word = "abc"
Output: 3
```

**Example 3:**
```
Input:  word = "ltcd"
Output: 0
```

---

## Constraints

- `1 <= word.length <= 10^5`
- `word consists of lowercase English letters.`
