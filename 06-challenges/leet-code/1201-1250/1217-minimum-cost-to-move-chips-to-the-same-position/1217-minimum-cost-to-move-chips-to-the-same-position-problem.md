# 1217. Minimum Cost to Move Chips to the Same Position

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/minimum-cost-to-move-chips-to-the-same-position/

---

## Problem Statement

We have `n` chips, where the position of the `i`-th chip is `position[i]`.

Moving a chip from position `x` to `x + 2` or `x - 2` is free. Moving a chip from position `x` to `x + 1` or `x - 1` costs 1.

Return the minimum cost to move all chips to the same position.

---

## Examples

**Example 1:**
```
Input:  position = [1,2,3]
Output: 1
```

---

## Constraints

- `1 <= position.length <= 100`
- `1 <= position[i] <= 10^9`
