# 944. Delete Columns to Make Sorted — Solution

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/delete-columns-to-make-sorted/

---

## Solution: Column Scan — O(n × m) time, O(1) space

**Idea:** For each column, check if it's sorted. Count unsorted columns.

**Complexity:**

| | |
|---|---|
| Time | O(n × m) |
| Space | O(1) |
