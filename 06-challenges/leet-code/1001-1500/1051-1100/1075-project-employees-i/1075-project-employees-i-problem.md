# 1075. Project Employees I

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/project-employees-i/

---

## Problem Statement

Table `Project`: (project_id, employee_id). Table `Employee`: (employee_id, name, experience_years).

Report the average experience years of all employees for each project, rounded to 2 decimals.
