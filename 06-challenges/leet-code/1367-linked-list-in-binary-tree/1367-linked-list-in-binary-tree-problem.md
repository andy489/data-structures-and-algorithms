# 1367. Linked List in Binary Tree

[Problem Link](https://leetcode.com/problems/linked-list-in-binary-tree/)

## Description
Given linked list head and binary tree root, return true if there's a downward path in the tree that matches the linked list from head.

## Examples
Input: head = [4,2,8], root = [1,4,4,null,2,2,null,1,null,6,8,...] → true

## Constraints
- Nodes in tree in [1, 2500], linked list in [1, 100]
