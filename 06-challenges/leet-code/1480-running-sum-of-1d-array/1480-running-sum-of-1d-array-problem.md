# 1480. Running Sum Of 1d Array

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/running-sum-of-1d-array/

---

## Problem Statement

Return the running sum of an array: running_sum[i] = sum(nums[0..i]).

---

## Examples

**Example 1:**
```
Input:  nums=[1,2,3,4]
Output: [1,3,6,10]
```

**Example 2:**
```
Input:  nums=[1,1,1,1,1]
Output: [1,2,3,4,5]
```

**Example 3:**
```
Input:  nums=[3,1,2,10,1]
Output: [3,4,6,16,17]
```

---

## Constraints

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^6`
