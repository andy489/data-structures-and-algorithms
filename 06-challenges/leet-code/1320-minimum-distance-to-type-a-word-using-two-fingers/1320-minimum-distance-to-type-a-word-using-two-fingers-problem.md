# 1320. Minimum Distance to Type a Word Using Two Fingers

[Problem Link](https://leetcode.com/problems/minimum-distance-to-type-a-word-using-two-fingers/)

## Description
On a keyboard with letters arranged in a 6x5 grid (A-Z top-left), type a word using two fingers minimizing total distance (Manhattan distance between consecutive positions of the same finger).

## Examples
Input: word = "CAKE" → 3

## Constraints
- 2 <= word.length <= 300
