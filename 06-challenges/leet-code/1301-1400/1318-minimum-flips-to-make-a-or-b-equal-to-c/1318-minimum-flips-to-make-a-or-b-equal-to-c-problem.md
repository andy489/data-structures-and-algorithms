# 1318. Minimum Flips to Make a OR b Equal to c

[Problem Link](https://leetcode.com/problems/minimum-flips-to-make-a-or-b-equal-to-c/)

## Description
Given a, b, c, return the minimum number of bit flips in a or b to make a OR b == c.

## Examples
Input: a = 2, b = 6, c = 5 → 3

## Constraints
- 1 <= a, b, c <= 10^9
