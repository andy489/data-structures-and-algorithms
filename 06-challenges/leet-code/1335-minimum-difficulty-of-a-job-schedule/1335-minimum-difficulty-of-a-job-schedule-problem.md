# 1335. Minimum Difficulty of a Job Schedule

[Problem Link](https://leetcode.com/problems/minimum-difficulty-of-a-job-schedule/)

## Description
Schedule jobDifficulty into d days (at least 1 job per day, in order). Day difficulty = max job difficulty that day. Return min total, or -1 if impossible.

## Examples
Input: jobDifficulty = [6,5,4,3,2,1], d = 2 → 7

## Constraints
- 1 <= jobDifficulty.length <= 300
- 0 <= jobDifficulty[i] <= 1000
- 1 <= d <= 10
