# 1460. Make Two Arrays Equal By Reversing Subarrays

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/make-two-arrays-equal-by-reversing-subarrays/

---

## Problem Statement

Return true if you can make `arr` equal to `target` by reversing any number of subarrays.

---

## Examples

**Example 1:**
```
Input:  target=[1,2,3,4],arr=[2,4,1,3]
Output: true
```

**Example 2:**
```
Input:  target=[7],arr=[7]
Output: true
```

**Example 3:**
```
Input:  target=[3,7,9],arr=[3,7,11]
Output: false
```

---

## Constraints

- `target.length == arr.length == n`
- `1 <= n <= 1000`
- `1 <= target[i] <= 1000`
- `1 <= arr[i] <= 1000`
