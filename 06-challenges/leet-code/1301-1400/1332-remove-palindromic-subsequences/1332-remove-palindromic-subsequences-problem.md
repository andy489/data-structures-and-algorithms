# 1332. Remove Palindromic Subsequences

[Problem Link](https://leetcode.com/problems/remove-palindromic-subsequences/)

## Description
Given string s consisting only of 'a' and 'b', return the minimum number of steps to make it empty by removing palindromic subsequences.

## Examples
Input: s = "ababa" → 1
Input: s = "abb" → 2

## Constraints
- 1 <= s.length <= 1000
