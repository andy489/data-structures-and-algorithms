# 1396. Design Underground System

[Problem Link](https://leetcode.com/problems/design-underground-system/)

## Description
Design UndergroundSystem: checkIn(id, stationName, t), checkOut(id, stationName, t), getAverageTime(startStation, endStation).

## Examples
undergroundSystem.checkIn(45, "Leyton", 3); checkOut(45, "Paradise", 8); getAverageTime("Leyton","Paradise") → 5.0

## Constraints
- 1 <= id, t <= 10^6
