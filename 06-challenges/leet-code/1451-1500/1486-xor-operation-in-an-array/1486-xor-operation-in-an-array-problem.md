# 1486. Xor Operation In An Array

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/xor-operation-in-an-array/

---

## Problem Statement

Return XOR of all elements of nums where nums[i] = start + 2*i for i in [0, n-1].

---

## Examples

**Example 1:**
```
Input:  n=5,start=0
Output: 8
```

**Example 2:**
```
Input:  n=4,start=3
Output: 8
```

**Example 3:**
```
Input:  n=1,start=7
Output: 7
```

---

## Constraints

- `1 <= n <= 1000`
- `0 <= start <= 1000`
- `n and start are both odd or both even`
