# 1315. Sum of Nodes with Even-Valued Grandparent

[Problem Link](https://leetcode.com/problems/sum-of-nodes-with-even-valued-grandparent/)

## Description
Given a binary tree, return the sum of values of nodes whose grandparent has an even value.

## Examples
Input: root = [6,7,8,2,7,1,3,9,null,1,4,null,null,null,5] → 18

## Constraints
- Number of nodes in [1, 10^4]
- 1 <= Node.val <= 100
