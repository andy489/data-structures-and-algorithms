# 1333. Filter Restaurants by Vegan-Friendly, Price and Distance

[Problem Link](https://leetcode.com/problems/filter-restaurants-by-vegan-friendly-price-and-distance/)

## Description
Given restaurants list [id, rating, veganFriendly, price, distance] and filters, return sorted restaurant IDs by rating desc then id desc.

## Examples
Input: restaurants = [[1,4,1,40,10],[2,8,0,50,5],[3,8,1,30,4],[4,10,0,10,3],[5,1,1,15,1]], veganFriendly=1, maxPrice=50, maxDistance=10 → [3,1,5]

## Constraints
- 1 <= restaurants.length <= 10^4
