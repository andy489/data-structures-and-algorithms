# 1497. Check If Array Pairs Are Divisible By K

**Difficulty:** Medium
**Link:** https://leetcode.com/problems/check-if-array-pairs-are-divisible-by-k/

---

## Problem Statement

Return true if the array can be split into n/2 pairs where each pair's sum is divisible by k.

---

## Examples

**Example 1:**
```
Input:  arr=[1,2,3,4,5,10,6,7,8,9],k=5
Output: true
```

**Example 2:**
```
Input:  arr=[1,2,3,4,5,6],k=7
Output: true
```

**Example 3:**
```
Input:  arr=[1,2,3,4,5,6],k=10
Output: false
```

---

## Constraints

- `arr.length == n`
- `1 <= n <= 10^5`
- `n is even`
- `1 <= arr[i] <= 10^9`
- `1 <= k <= 10^5`
