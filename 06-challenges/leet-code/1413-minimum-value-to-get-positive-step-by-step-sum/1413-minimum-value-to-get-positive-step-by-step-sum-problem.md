# 1413. Minimum Value To Get Positive Step By Step Sum

**Difficulty:** Easy
**Link:** https://leetcode.com/problems/minimum-value-to-get-positive-step-by-step-sum/

---

## Problem Statement

Return the minimum positive `startValue` such that the step-by-step sum of `startValue + nums[i]` never drops below 1.

---

## Examples

**Example 1:**
```
Input:  nums = [-3,2,-3,4,2]
Output: 5
```

**Example 2:**
```
Input:  nums = [1,2]
Output: 1
```

**Example 3:**
```
Input:  nums = [1,-2,-3]
Output: 5
```

---

## Constraints

- `1 <= nums.length <= 100`
- `-100 <= nums[i] <= 100`
